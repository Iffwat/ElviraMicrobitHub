# Phase 8 — Remote Access (optional)

**Status:** ⏳ Coming soon

## Planned scope
- Remote viewing and control through a local web viewer or an MQTT bridge
- **Token authentication**, unlike MakerLink's 4-digit room code
- Per-card permissions **checked on the host** before any command is forwarded to the robot
- Rate limiting for remote commands

## Done when
A remote viewer can watch and control only the cards the host allows.
